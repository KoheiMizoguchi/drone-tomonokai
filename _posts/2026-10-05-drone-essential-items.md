ドローンの持ち物を紹介する記事には、10〜20個のアイテムが並んでいることがよくあります。でも、はじめから全部そろえる必要はありません。この記事では、**最初に必ずそろえるもの**と、**慣れてからでよいもの**を分けて紹介します。

## 先に結論

- 買う前に、**本体に何が付いてくるか**を確認する。予備のバッテリーや充電器がセットになった商品もある
- 最初にそろえるのは、**予備プロペラ・予備バッテリー・microSDカード・風速計・操縦用のスマホと充電**の5つ
- 100g以上の機体は、道具とは別に、**機体への登録記号の表示**が必要

## まず、付属品を確認する

同じ機体でも、「本体だけ」の商品と、予備のバッテリーや充電器、収納バッグなどが付いた「セット」の商品があります。セットのほうが、あとから一つずつ買うより安くなることもあります。

注文する前に、商品ページや取扱説明書の「同梱品」を見て、次の点を確認します。

- 予備のプロペラが付いているか
- バッテリーが何本付いているか、充電器が付いているか
- 操縦にスマホが必要か（送信機に画面が付いている機種もある）
- microSDカードが付いているか、本体に保存できる容量があるか

## 最初にそろえる5つ

### 1. 予備プロペラ

- **なぜ必要か**：プロペラは小さな接触でも欠けたり、ひびが入ったりする消耗品。傷んだまま飛ばすと危ない
- **選ぶとき**：必ず自分の機種に合うもの。回る向きの違う2種類があるので、付け間違えない

### 2. 予備バッテリー

- **なぜ必要か**：1本で飛べる時間は短い。練習では1本だとすぐに終わってしまう
- **選ぶとき**：自分の機種に合う純正品。練習するなら2〜3本あると、交代で充電しながら続けられる

### 3. microSDカード

- **なぜ必要か**：機種によっては、カードを入れないと写真や動画を保存できない
- **選ぶとき**：取扱説明書にある「推奨のカード」（容量と書き込みの速さ）を選ぶ

### 4. 風速計

- **なぜ必要か**：風はドローンにとって一番の敵。目や体の感覚では強さが分かりにくい
- **選ぶとき**：手のひらサイズの電池式で十分。国の標準マニュアルでは、風速5m/s以上では飛ばさないことになっている

風速計で測れるのは、手元の高さの風です。上空は地上より風が強いことがよくあります。地上で5m/sぎりぎりなら、その日はやめておくくらいの余裕をもって判断します。

### 5. 操縦用のスマホと充電

- **なぜ必要か**：多くの機種は、スマホのアプリで操縦や映像の確認をする。途中で電池が切れると危ない
- **選ぶとき**：機種の「対応端末」を確認。予備にスマホ用のモバイルバッテリーを持っていく

## 道具ではないけれど、必ず用意すること

100g以上の機体（航空法上の「無人航空機」）には、次のことが必要です。

- **登録記号の表示**：機体を国に登録したら、飛ばす前に登録記号を機体に表示します。重さ25kg未満の機体は、文字の高さ3mm以上で、シールや油性ペンなど消えにくい方法で書きます。表示する場所は、外から見える胴体のうち、工具を使わないと外せない場所です。**バッテリーのふたなど、工具なしで外せる場所には表示できません。**
- **飛ばす前の確認**：国のガイドラインでは、飛ばす前に、天気が安全か、機体に傷や故障がないか、バッテリーが十分に充電されているかを確かめることが必須とされています。特典PDF「飛行前後点検チェックリスト」を使うと、確認もれを防げます。
- **飛行日誌**：許可・承認が必要な飛ばし方（特定飛行）をするときは、記録が義務です。それ以外の飛行でも、記録しておくことがすすめられています。様式は国土交通省のページからダウンロードできます。

## 慣れてきたら、あると便利なもの

| アイテム | 役に立つ場面 |
|---|---|
| ランディング<wbr>パッド（離着陸用の<wbr>マット） | 芝生や砂地で、プロペラが砂や小石を巻き上げるのを防ぐ |
| サングラス・<wbr>モニターフード | 晴れた日に、スマホの画面を見やすくする |
| 収納ケース | 機体やプロペラを、持ち運ぶときの衝撃から守る |
| プロペラガード | 人や物に当たったときの被害を小さくする。付けると飛び方に影響することがあるので、取扱説明書を確認する |
| 帽子・日焼け止め | 飛ばせるのは基本的に日中なので、屋外で長くいるときに |
| カイロ | 寒い日にバッテリーが冷えすぎるのを防ぐ（バッテリーは低温で性能が落ちる） |
| 撮影用の<wbr>レンズフィルター | 水面の反射をおさえるなど、撮影にこだわりたくなったら |

## 「必須」と書かれがちでも、注意したいもの

- **双眼鏡**：国のガイドラインでは、目で見て飛ばす「目視」は「直接肉眼による」ものとされ、モニターを見ながらの飛行は目視外飛行の例とされています。双眼鏡で探さないと見えないほど遠くに飛ばすのは、目視の範囲を超えているおそれがあります。双眼鏡は、見失ったときに探す手助け程度に考えます。
- **業務向けの道具**：無線のインカムや大型のヘリポート、反射ベスト、飛行中の看板などは、主に仕事で飛ばす人向けです。趣味の練習で最初からそろえる必要はありません。
- **バッテリーの持ち運び**：ドローンのバッテリーは、衝撃や熱に弱いものがあります。持ち運ぶときは専用のケースに入れ、車内に置きっぱなしにしないようにします。国のガイドラインは、電池などの火災に備えて、消火器などを準備することもすすめています。

## まとめ：最初の買い物チェック

| 確認すること | 済んだら |
|---|---|
| 本体に付いてくるもの（予備プロペラ・バッテリー・充電器・カード）を確認した | □ |
| 足りない分の予備プロペラ・予備バッテリーをそろえた（自分の機種に合うもの） | □ |
| 推奨のmicroSDカードを用意した | □ |
| 風速計を用意した | □ |
| 操縦用のスマホが対応端末か確認し、スマホ用のモバイルバッテリーを用意した | □ |
| 100g以上の機体なら、登録して登録記号を表示した | □ |

この記事の本文では、特定の商品をおすすめしていません。どの商品を選ぶかは、自分の機種の取扱説明書と対応表で確かめてください。
